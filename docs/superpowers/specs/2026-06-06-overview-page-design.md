# 赛事概览页设计文档 (World Cup Hub Page)

> 日期：2026-06-06
> 状态：已确认
> 关联：全局导航方案 A（顶部导航 + 全宽内容）

---

## 1. 页面定位

赛事概览页是整个看板的首页（路由 `/`），以 **48强分组全览** 为核心体验，辅以三个数据排行图表。用户可以一目了然地看到所有分组情况，并快速跳转到具体球队画像。

---

## 2. 页面结构（从上到下）

### 2.1 顶部导航栏（全局复用）

- 高度：48px
- 背景：`#1a1a2e`（深海军蓝）
- 内容：左侧 Logo `🏆 WC 2026` + 三个导航标签（赛事概览 / 球队画像 / 对阵模拟）
- 当前页面标签高亮（红色下划线 `#e53e3e`）

### 2.2 分组概览区（主视觉区，~60%）

**区域标题**：
- 主标题："48强分组概览"（18px，粗体）
- 副标题："2026 美加墨世界杯 · 12组 · 48支球队"（11px，灰色）

**分组卡片网格**：
- 布局：4列 × 3行 CSS Grid，`gap: 8px`
- 背景：`#f7f8fa`（浅灰底）
- 卡片样式：
  - 白色背景，圆角 8px，`border: 1px solid #eef0f3`
  - Hover 效果：轻微上浮（`translateY(-2px)`）+ 阴影加深
  - 内边距：10px

**每张卡片内容**：
- 组名标签：大写字母 + "组"（如 `A组`），10px 粗体，每个组用不同颜色（12 组循环 6 色）
  - A/G: `#e53e3e`（红）, B/H: `#3182ce`（蓝）, C/I: `#38a169`（绿）
  - D/J: `#d69e2e`（金）, E/K: `#805ad5`（紫）, F/L: `#ed8936`（橙）
- 4 支球队行，按综合评分从高到低排列
- 每行结构：
  ```
  [国旗图片 18×13px] [球队名]  ──────── [综合评分]
  ```
- 国旗图片来源：`https://flagcdn.com/w20/{country_code}.png`
  - country_code 使用 ISO 3166-1 alpha-2 小写代码
  - 特殊处理：英格兰 `gb-eng`
- 综合评分：右对齐，蓝色 `#3b82f6`，粗体，10px

**交互**：
- 点击卡片内任意球队名 → 跳转到 `/team/[id]` 球队画像页

### 2.3 数据排行区（辅助区，~30%）

**区域标题**："数据排行"（15px，粗体）

**三图并排布局**：
- CSS Grid：`grid-template-columns: 1fr 1fr 1fr`，`gap: 10px`
- 每张图表卡片：白色背景，圆角 8px，`border: 1px solid #eef0f3`，内边距 12px

**图表 1 — 🏆 夺冠赔率排行**：
- 类型：水平条形图，展示 Top 10
- 每行：`[国旗14px] [球队名] [渐变条] [赔率值]`
- 条形颜色：每个球队独立渐变色（红/蓝/绿/金/紫循环）
- 赔率值越小，条越长（使用倒数映射）

**图表 2 — 💰 总身价排行**：
- 类型：水平条形图，展示 Top 10
- 每行：`[国旗14px] [球队名] [渐变条] [身价值]`
- 条形颜色：同上独立渐变色
- 身价格式：`€1.4B` / `€850M`

**图表 3 — 📊 综合能力排行**：
- 类型：水平条形图，展示 Top 10
- 每行：`[国旗14px] [球队名] [蓝色渐变条] [评分]`
- 条形颜色：统一蓝色渐变 `linear-gradient(90deg, #3b82f6, #60a5fa)`
- 综合能力 = 雷达图八维指标的加权平均分

**图表统一规格**：
- 条形高度：14px
- 背景条：`#eef0f3`，圆角 3px
- 条形值标签：右对齐，粗体，与条形同色系

### 2.4 页脚

- 背景：`#f7f8fa`
- 上边框：`1px solid #e2e8f0`
- 左侧：数据更新时间（如 "数据更新时间：2026-06-04 12:00 UTC"）
- 右侧：数据源说明（"数据源：API-Football · Bet365 · 综合模型"）
- 字号：10px，灰色 `#aaa`

## 3. 组件拆分

| 组件名 | 职责 | 数据源 |
|--------|------|--------|
| `TopNav` | 全局顶部导航栏，三个页面标签 | 静态配置 |
| `GroupCard` | 单个分组卡片，渲染4支球队 | `profile.json` × 4 + `radar_data.json` × 4 |
| `TeamRow` | 卡片内单支球队行（国旗+名+评分） | `profile.json` + `radar_data.json` |
| `RankingChart` | 水平条形图排行（复用于三个图表） | 48队的 `radar_data.json` + `profile.json` + 赔率数据 |
| `Footer` | 页脚信息 | 静态 + 数据更新时间 |

## 4. 数据需求

概览页需要读取全部 48 支球队的以下数据：

| 字段 | 来源文件 | 用途 |
|------|---------|------|
| `team_id` | `profile.json` | 路由跳转标识 |
| `team_name` | `profile.json` | 显示球队名 |
| `country_code` | `profile.json`（新增字段） | 国旗图片 URL 构建 |
| `group` | `profile.json`（新增字段） | 分组归属 |
| `total_value_m_euros` | `profile.json` | 总身价排行 |
| 综合评分 | `radar_data.json` 的 metrics 加权平均 | 分组卡片 + 综合能力排行 |
| 夺冠赔率 | `1_raw_data/odds/` | 夺冠赔率排行 |

**`profile.json` 需新增字段**：
```json
{
  "country_code": "ar",
  "group": "A"
}
```

---

## 5. 综合评分计算规则

综合评分 = 八维雷达指标的算术平均值：

```
overall_score = (attack + defense + control + status + experience + place_kick + superstar + penalty) / 8
```

保留一位小数，用于分组卡片排序和综合能力排行图。

## 6. 响应式策略

| 断点 | 分组网格列数 | 图表区列数 |
|------|------------|-----------|
| ≥ 1280px | 4 列 | 3 列 |
| 768px–1279px | 3 列 | 2 列（综合能力排行换行到下方） |
| < 768px | 2 列 | 1 列（纵向堆叠） |

---

## 7. 设计约束

- 国旗图片依赖外部 CDN（flagcdn.com），需添加 fallback：加载失败时显示球队 ISO 代码缩写
- 图表排行只展示 Top 10，避免页面过长
- 分组内球队按综合评分降序排列
- 页面使用 Next.js SSG + ISR，数据通过本地 JSON 文件提供
